    How This Percentage Calculator Works

    You have two numbers and want to know how far one moved from the other. It might be a raise you were just offered, a bill that crept up, or a price that looks higher than last month. Type the original value and the new value into the percentage increase calculator above and the percentage appears as you type. If you already know the percentage, enter it with either value and the missing number is filled in.

    How to Calculate Percentage Increase

    Subtract the old number from the new one, divide the difference by the old number, and multiply by 100. Written out: ((New − Old) / Old) × 100. The percentage increase calculator runs exactly this formula and lists each step under Calculation Steps, so you can check the working or copy it into a report.

    A Quick Example

    Rent goes from $1,200 to $1,380 a month. The difference is $180, and 180 ÷ 1,200 = 0.15, so the rent rose 15%. Type 1200 and 1380 into the percentage increase calculator to confirm it, then try your own figures.

    Salary and Pay Raise Calculations

    Job offers and annual reviews are where most people reach for a percentage increase calculator. Going from $55,000 to $62,000 is a 12.7% raise. If HR quotes a percentage instead, put your current salary in the first box and the percentage in the third: a 4.5% raise on $62,000 comes to $64,790.

    Hourly Wage Increases

    Hourly pay works the same way. A move from $18 to $21 an hour is a 16.7% increase. When you compare gig or part-time offers with awkward rates like $17.35 and $19.10, a percentage increase calculator turns them into one number you can line up side by side.

    Price and Cost Increases

    Groceries, rent, subscriptions and supplier invoices all go up over time. Milk moving from $3.49 to $4.19 doesn't sound like much until you see it is a 20% jump. Shop owners use the same sum to decide whether to absorb a supplier's cost increase or pass it on. For a version with retail examples and the .99 pricing problem, see the price increase calculator.

    Monthly and Recurring Cost Tracking

    Comparing January's bill with March's, or this year's total with last year's, is clearer as a percentage than in dollars, and a percentage increase calculator makes that comparison quick. Got a whole list of bills? Paste them into the Batch tool and every change is worked out at once, with a total for the whole list.

    Investment and Property Value Growth

    Investors talk in percentages because dollar amounts on their own mislead. A $5,000 gain on a $50,000 portfolio is 10%; the same $5,000 on $500,000 is only 1%. A house bought for $320,000 and now valued at $385,000 has gained 20.3%. The percentage increase calculator treats stock prices, fund returns and property values the same way, from cents to millions.

    Percentage Decrease

    When the new value is lower, the result is negative and the display turns red. A jacket marked down from $89.99 to $74.99 dropped 16.67%: the difference is $15, and 15 ÷ 89.99 = 0.1667. You don't need a separate tool for this. The percentage increase calculator labels a fall as a decrease on its own, so it doubles as a percentage change calculator in either direction.

    Working Back to the Original Value

    Sometimes you know the result and the percentage but not where you started. A price is $138 after a 15% increase, so the original was 138 ÷ 1.15 = $120. Enter 138 as the new value and 15 as the percentage, leave the original empty, and the percentage increase calculator fills it in. This is handy for taking out a markup or a sales tax that is already included in a price.

    When the Original Value Is Zero

    A change from 0 has no percentage, because the formula divides by the original value. Going from 0 to 50 customers is a gain of 50 customers, not an infinite percentage. Report the change as a plain number in that case; the percentage increase calculator shows a note instead of a result.

    Percentage Increase vs. Percentage Difference

    Percentage increase has a direction: it measures the change against the starting value. Percentage difference compares two values that have no before and after, such as two shops' prices on the same day, and divides by their average. From 80 to 100 is a 25% increase, but the percentage difference between 80 and 100 is about 22.2%. Use the percentage increase calculator whenever one number clearly came first.

    Several Changes in a Row

    A 50% increase followed by a 50% decrease does not bring you back to the start: 100 becomes 150, and 150 minus 50% is 75. Each step is measured from the new amount, so changes multiply rather than add, and one pass through a percentage increase calculator only covers one step. The Chained Changes tool works out the real total for any number of steps and shows how far it is from simply adding them up.

    Percentage Increase in Excel and Google Sheets

    With the old value in A2 and the new value in B2, use =(B2-A2)/ABS(A2) and format the cell as a percentage. To raise a value by a percentage, use =A2*(1+C2) with the percentage in C2, typed as 15%. The percentage increase calculator shows the matching formula next to every result, ready to copy into your sheet.

    Common Mistakes with Percentages

    Percentage Points vs. Percent Change

    An interest rate that moves from 3% to 5% rose by 2 percentage points, but by 66.7% in relative terms. News reports mix these up all the time. If a figure sounds surprisingly large or small, run both numbers through the percentage increase calculator to see which one is meant.

    Dividing by the Wrong Number

    The change is always divided by the starting value, not the new one. From 80 to 100 is 20 ÷ 80 = 25%. Dividing by 100 instead gives 20%, which is the size of the drop if you go back from 100 to 80.

    Frequently Asked Questions

    How do I calculate percentage increase from one number to another?

    Subtract the original from the new value, divide by the original, and multiply by 100. Or type both numbers into the percentage increase calculator above and skip the arithmetic.

    What's the difference between percentage increase and percentage change?

    "Increase" means the value went up. "Change" is neutral and covers both directions. This tool handles either one: green for an increase, red for a decrease.

    Can I use this to calculate a percentage decrease?

    Yes. If the new value is lower, the percentage increase calculator returns a negative result and labels it as a decrease.

    How do I find the new value after a known percentage increase?

    Multiply the original by (1 + percentage ÷ 100). A $200 item with a 15% increase becomes $200 × 1.15 = $230. Enter the original and the percentage above and the new value fills in, or use the "Quick: Value + Percent" box.

    Can I paste numbers with dollar signs, commas or percent signs?

    Yes. Values such as $1,200, 15% or 1.234,56 are read correctly, so you can paste straight from a spreadsheet or a web page.

    Does this work for large numbers like property values or revenue?

    It works at any scale, from a $0.46 per-item price increase to revenue in the millions. The formula is the same either way.
