    Batch: Many Changes at Once

    Paste one pair per line: original value, then new value. Rows copied from Excel or Google Sheets work as they are, and you can put a name in front of each pair.

    Chained Changes

    Apply several percentage changes one after another, like +20% and then −10%. The total is not the sum of the steps, because each step starts from the new amount. This shows the real result.
